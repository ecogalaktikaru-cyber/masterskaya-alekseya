# ТЗ: сайт-визитка «Первый Пар» (бани Алексея)

## Контекст

Клиент — Алексей, частный мастер, строит бани из дерева и камня с террасами в Москве и МО. Средний чек 700 тыс — 2 млн ₽. Компании и бренда нет, рабочее название — **«Первый Пар»** (может смениться, см. задачу 6).

Сайт — одностраничная визитка. Стек: **чистый HTML + CSS + минимум JS, без фреймворков и сборки**. Один файл `index.html`, всё внутри. Так и оставляем — сайт должен открываться с любого статик-хостинга без билда.

Макет уже собран и лежит в `index.html` в корне проекта. Его **не переписывать с нуля** — доводить точечно.

---

## Задача 1. Деплой (первым делом)

1. Инициализировать git-репозиторий в `~/Projects/pervy-par/`.
2. Создать публичную репу `pervy-par` на GitHub, запушить.
3. Включить GitHub Pages: branch `main`, папка `/root`.
4. Вернуть рабочую ссылку.

Домен пока не покупаем — сначала показываем Алексею превью на `github.io`.

---

## Задача 2. Заглушки, которые обязательно закрыть

В коде есть места с явными плейсхолдерами. Собрать их в чеклист и заменить, когда придут данные от клиента:

| Что | Где в коде | Чем заменить |
|---|---|---|
| Телефон | футер, `href="tel:+70000000000"` | реальный номер Алексея |
| Telegram | JS, `https://t.me/USERNAME` | реальный ник |
| WhatsApp | футер, `href="#"` | `https://wa.me/7XXXXXXXXXX` |
| ИНН / ИП | футер | реквизиты Алексея |
| 5 фотослотов | блоки `.photo` с `data-slot` | реальные фото |
| Цифры в hero | `14 лет`, `1 мастер`, `24ч` | подтверждённые клиентом |
| Три объекта | секция `#objects` | реальные города, метраж, сроки, суммы |

**Важно:** до получения фактуры от Алексея ничего не выдумывать. Если данных нет — оставить плейсхолдер видимым, а не подставить правдоподобное. Цифры на сайте частного мастера — это его репутация.

## Задача 3. Калькулятор — пересчитать под реальную себестоимость

Сейчас в JS зашиты мои рыночные прикидки:

```js
const BASE = 38000;              // ₽/м² базовой каркасной коробки под ключ
mat:  каркас 1 / сухой брус 1.25 / клеёный 1.5 / бревно 1.65
ter:  0 / 120 000 / 260 000
stn:  0 / 150 000 / 320 000 / 520 000
вилка: total * 0.92 — total * 1.12
```

Забрать у Алексея его реальные цифры по каждому пункту и переписать константы. Логику расчёта не менять — она рабочая.

**Критично:** нижняя граница вилки не должна быть ниже той суммы, за которую Алексей реально готов взяться. Иначе калькулятор станет ловушкой — клиент придёт с ожиданием, которое не закрыть.

## Задача 4. Форма заявки

Сейчас форма собирает строку и открывает `t.me/USERNAME?text=...`. Оставить как основной путь (у Алексея нет CRM), но добавить:

- Валидацию телефона — маска `+7 (___) ___-__-__`, без внешних библиотек.
- Фолбэк: если `window.open` заблокирован попапоблокером — показать номер и ник текстом, чтобы человек скопировал вручную.
- Дублировать заявку на почту через Formspree или аналог (бесплатный тариф). Ключ вынести в отдельную константу вверху скрипта с комментарием.

---

## Задача 5. Техничка перед показом клиенту

- **Мета и OG:** `og:title`, `og:description`, `og:image` (превью 1200×630, сделать из главного фото), `twitter:card`.
- **Favicon:** сгенерировать из логотипа-надписи, положить `favicon.svg` + `apple-touch-icon.png`.
- **Шрифты:** сейчас Google Fonts с CDN. Скачать Playfair Display и Inter (кириллица, только нужные начертания), положить в `/fonts`, подключить локально через `@font-face` с `font-display: swap`. Google Fonts из РФ работает нестабильно — это не косметика, это доступность сайта.
- **Schema.org:** разметка `LocalBusiness` + `FAQPage` в JSON-LD. FAQ на странице уже есть, взять оттуда.
- **`robots.txt` и `sitemap.xml`** — минимальные, страница индексируемая.
- **Lighthouse:** цель — Performance и Accessibility 95+. Сейчас узкое место одно: фото. Все реальные фотографии прогнать в WebP, задать `width`/`height` на каждом `<img>`, `loading="lazy"` для всего ниже первого экрана.

## Задача 6. Мобильное меню

Кнопка-бургер сейчас заглушка — просто скроллит к калькулятору. Сделать нормальное: выезжающая панель на весь экран, те же пять пунктов навигации плюс телефон крупно. Закрытие по клику вне панели и по Esc. Без библиотек.

## Задача 7. Нейминг (обсудить с заказчиком до финального деплоя)

Имя в макете стоит в трёх местах: `<title>`, `.brand-mark` в шапке, подпись в блоке «О мастере» и футер. Варианты для обсуждения с Алексеем:

- **Личный бренд:** «Артель Алексея», «Мастерская Алексея»
- **Отвлечённый:** «Тёплый камень», «Венец», «Обжиг»
- **Банно-русский:** «Первый пар» *(в макете)*, «Каменка», «Полок»

После выбора — проверить свободные домены в `.ru`, взять два-три варианта на выбор.

---

## Чего НЕ делать

- Не тащить React, Vue, Tailwind, сборщики. Сайт должен редактироваться открытием одного файла в редакторе.
- Не добавлять слайдеры-карусели, попапы «оставьте заявку» через 15 секунд, счётчики обратного отсчёта. Позиционирование — спокойный мастер, а не инфобизнес.
- Не расширять портфолио до сетки из 12 карточек. Три больших объекта — сознательное решение: у клиента мало фото, и редкость работает на образ «беру немного заказов».
- Не убирать блок «три ошибки» и оплату по этапам — это основные конверсионные узлы.

---

## Критерии приёмки

1. Сайт открывается по ссылке GitHub Pages, грузится меньше 2 секунд на 4G.
2. Калькулятор считает по реальным цифрам Алексея, вилка не занижена.
3. Форма доходит и в Telegram, и на почту.
4. Ни одного плейсхолдера в продакшене — либо реальные данные, либо блок скрыт.
5. Всё корректно на iPhone SE (375px) и на 1440px.
6. Lighthouse: Performance 90+, Accessibility 95+, SEO 100.
